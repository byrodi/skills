# Security Policy

## Reporting a vulnerability

Do not open a public issue. A problem in one skill goes to a private report in that skill's repository, for example https://github.com/byrodi/humanizer/security/advisories/new. A problem in the marketplace file itself, such as an entry that points to the wrong source, goes here:
https://github.com/byrodi/skills/security/advisories/new

Include the skill, the commit you use, steps to reproduce and the impact you expect. Reports are acknowledged within 7 days. A confirmed vulnerability is fixed on `main` and disclosed through a GitHub Security Advisory, normally within 90 days of the report.
